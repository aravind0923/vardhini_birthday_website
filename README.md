# Happy Birthday, Vardhini! 💜

A responsive birthday wishes webpage with a purple-and-gold floral theme, six supplied photos, a photo lightbox, floating decorations, an original browser-generated chime melody, a candle-blowing interaction, and a friendship letter.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.
3. Keep the `assets` folder beside `index.html`; do not move the images out of it.

Music starts only when the visitor taps **Play music**, because mobile browsers require a user gesture before audio can play. The tune is generated by the browser; no music file is needed. Google Fonts are optional online fonts; the site uses fallbacks if offline.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `vardhini-birthday` (or another name you like).
2. On the repository page, choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `script.js`, and the complete `assets` folder. If the browser uploader has trouble with folders, upload the ZIP contents after extracting it locally; make sure the six images are inside `assets/`.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. GitHub will show your public URL, usually:
   `https://YOUR-USERNAME.github.io/vardhini-birthday/`
9. Open the URL on your phone to test it, then share it with Vardhini on WhatsApp.

## Notes
- The website is static: it does not collect personal data or need API keys.
- Since the repository is public, anyone with the link can view the webpage and photos. Use a private sharing option instead if you do not want the photos public.
- To change the message, edit the text in `index.html`. To change photo captions, edit the `photoData` list in `script.js` and the matching caption spans in `index.html`.
